HOW TO UPDATE YOUR ADMIN APK
============================
1. In your GitHub repo (fohowzodiacapp) upload/replace ALL files from this folder
   (keep the hidden ".github" folder). ADMIN_URL.txt is already set to
   http://fohowzodiacug.xo.je/admin.php
2. Open the Actions tab - the build starts by itself. When it shows a green tick,
   download the artifact "Fohow-Zodiac-Admin-APK", unzip, and install app-debug.apk
   (uninstall the old version first if Android refuses to update).
3. IMPORTANT: also replace admin.php on your InfinityFree site with the admin.php
   file provided. It fixes the phone layout of the dashboard.

SECURITY FEATURES
- Opens with the big Zodiac logo, then asks for your phone PIN / pattern / fingerprint.
- Locks again every time you leave the app (Home, Recents, another app, screen off).
- After 5 minutes away you are also signed out of the dashboard (password needed again).
- Screenshots, screen recording and the recent-apps preview are blocked.
- The phone must have a screen lock set, otherwise the app will not open.
